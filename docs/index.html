Teaching a small language model to read CT reports

I fine-tuned a 4-billion-parameter open model on a MacBook so that it turns a radiologist's free-text chest CT report into a structured list of findings, and backs every finding with a quote from the report. Then I measured how often each model version claimed something it couldn't back up.

Real examples

Left: the radiologist's report, with the model's quotes highlighted where they were found in the text. Right: what the reference labels say versus what the model said, and whether each claim came with a quote.

Notes. Test reports come from patients never used in training. "Claims without evidence" counts findings a model marked present whose quote was missing, under three words, or not found verbatim in the report. Reference labels come from CT-RATE and were produced by a text classifier, so "agreement" is not the same as clinical accuracy. The quote check catches invented text, not misread text; a clinician audit in the repository covers that gap on a sample.
